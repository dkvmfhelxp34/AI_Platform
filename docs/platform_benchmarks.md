# 해양 부이 모니터링 플랫폼 벤치마크 — 공공기관 사례 조사와 도입 패턴

> 조사일: 2026-07-15 · 조사자: Claude(웹 리서치, WebFetch/WebSearch 병렬 조사) · 목적: 국내외 공공기관의 해양/부이 모니터링 플랫폼을 실측 조사하여, 우리 시연 플랫폼이 "예쁜 목업"이 아니라 **"신뢰할 수 있는 운영 도구(trustworthy ops tool)"** 로 보이게 만드는 구체적·채택 가능한 UI/기능 패턴을 추출한다.
>
> **배경(심사 지적):** 5인 전문가 리뷰에서 우리 플랫폼이 "pretty mockup"처럼 읽히고 "trustworthy ops tool"로는 부족하다는 지적. → 실제 운영 플랫폼들이 "권위 있고·과학적이고·유용해" 보이는 이유(데이터 출처·타임스탬프·QC 투명성·단위·불확실성·계측기 메타)를 학습해 이식하는 것이 이 문서의 초점.
>
> **관련 문서:** 데이터 소스·파라미터는 [`API_RESEARCH.md`](API_RESEARCH.md), 과거이력 확보는 [`historical_data_probe.md`](historical_data_probe.md)·[`oceangrid_probe.md`](oceangrid_probe.md), UI 개편 방향은 [`ui_revision_notes.md`](ui_revision_notes.md).

## 조사 방법과 한계

- 각 플랫폼의 실제 페이지를 WebFetch로 열어 **직접 관찰**한 내용을 우선하고, JS SPA라 정적 fetch로 렌더링이 안 되는 경우(대부분의 지도 뷰어) 공식 도움말·기술문서·데이터포털·검색 스니펫으로 보완했다. **직접 관찰(fetch)** 과 **문서/검색 기반 추정(search)** 을 구분해 표기한다.
- 정직한 공통 한계: **거의 모든 라이브 지도/차트가 클라이언트 렌더링 SPA**라서, 마커 아이콘 형태·클러스터링·베이스맵 픽셀·팝업 레이아웃·차트 축/그리드/정상범위 밴드의 픽셀 단위 세부는 이 조사 방식으로 완전히 확증되지 않은 항목이 있다. 반면 **서버 렌더링되는 것들(NDBC station 페이지, 각종 데이터포털·ERDDAP·FAQ·QC 문서·제원 API)** 은 1차 확인됨. NDBC와 CO-OPS는 가장 깊게 확인되어 이 문서의 기준점(reference standard) 역할을 한다.

# 1. 플랫폼별 캡슐 (URL + 주목할 점)

## 1-A. 국내(domestic)

### KHOA 바다누리 해양정보 서비스 (국립해양조사원)
- **URL:** http://www.khoa.go.kr/oceangrid/ (KOOFS GIS 뷰어), 영문 소개 `/oceangrid/koofs/eng/introduce/network.do`
- **주목할 점:**
  - 관측망을 **5개 유형**으로 조직: 조위관측소 / 해양관측소(등표·돌핀, 파랑) / **해양관측부이(계류 부이)** / 연안류·HF레이더 / 해양과학기지. → "센서 클래스가 조직 원리"인 정보구조.
  - **파라미터별 다단계 색 범례 + 실제 수치 임계 밴드**가 페이지 텍스트로 확인됨: 수온(℃, <23→29+ 다단), 파고(m, 0.16→0.64+), 유속(cm/s, 38→125+), 염분(PSU 5단), 조위/기온/기압/풍속 스케일. → **"at-a-glance 상태 인코딩"의 좋은 참고**.
  - **격자(grid) 공간 선택**("구역 선택") 방식 — 점 마커 클릭뿐 아니라 지역/셀 단위 진입.
  - **원시 실시간 vs QC 후처리 2계층** 데이터 모델(등록사용자 QC 접근) — 학계 문서로 확인. 다만 지도 UI에는 QC 구분이 시각 표출되지 않음.
  - 생활밀착형 파생 서비스(스마트 조석예보, **갯벌 노출 위험 알리미**, 생활 해양지수)를 원시 지도와 병행.
- (내부 조사로 확보한 비공식 endpoint·과거이력 백필 방법은 [`oceangrid_probe.md`](oceangrid_probe.md) 참조.)

### 기상청 해양기상정보포털 (marine.kma.go.kr)
- **URL:** https://marine.kma.go.kr, 데이터 다운로드 https://data.kma.go.kr/data/sea/selectBuoyRltmList.do
- **주목할 점:**
  - **계측기 종류를 별도 레이어/카테고리로 분리**(해양기상부이·파고부이·등표·시정 …) — 단일 통합 마커 레이어가 아니라 카테고리 우선 내비.
  - 데이터포털 쪽에서 확인: **분/시간/일 해상도 탭**, 지점 선택 = 지도 + 지역 드롭다운(이중), 기간 = **이중 캘린더 + 시각 드롭다운**, **CSV·Excel 다운로드 + OPEN-API 탭**, 관측방법 문서(해양기상관측지침) 링크.
  - **특보 시스템**: 주의보/경보 2단, **정량 임계 공개**(예: 풍랑주의보 = 10분 평균 풍속 ≥14 m/s 3시간+ 또는 유의파고 >3 m).
  - 데이터 계보 명시("분자료는 2016.3부터", "1996년부터") — 한계를 숨기지 않음.
  - 관측 갱신 주기 명시: 해양기상부이 10~30분, 등표·파고부이 시간별.

### 국립수산과학원 실시간 해양환경 어장정보시스템 / KODC
- **URL:** https://www.nifs.go.kr/kodc/ (한국해양자료센터), RISA 실시간 지도 https://www.nifs.go.kr/risa/
- **주목할 점:**
  - **가장 강력한 공식 인증 신호**: **UNESCO/IOC 공인 국가데이터센터(국내 유일)**, **ISO 9001 10년 연속**, PICES 공공데이터상. → 신뢰성 배지 전략의 교과서.
  - 관측 항목에 **관측심도(depth)** 포함(수온·염분·용존산소·클로로필), **QC(품질관리) 적용** 명시, 실시간 30분 주기.
  - KODC: **장기 추세 시각화**(한국 해역 vs 전지구), **수요자 중심 다운로드**, QC 자료 공개 지연을 "이듬해→~30일"로 단축했다고 공표(데이터 신선도 개선을 홍보 포인트로 사용).
  - **고수온속보** + East-Sea 부이 **SMS 경보**. (연속 시계열 부이라기보다 저빈도 정선조사가 KODC 본체이나, RISA/동해 어장환경 시스템이 부이 기반.)

### 해양수산부 / 종합해양과학기지 (KIOST KORS)
- **URL:** https://kors.kiost.ac.kr/ (이어도·가거초·소청초·왕돌초 + 해양부이)
- **주목할 점:**
  - **추적 가능한 다기관 출처 사슬**이 신뢰성 서사의 핵심: KIOST 구축/운영 → 무궁화 위성 중계 → KHOA 바다누리(8개 항목 공개) + KMA(태풍예보 피드). 이어도가 태풍 상륙경로의 ~60%에 위치, 8~12시간 선행 관측 → "과학적 정당성" 앵커.
  - **공학 등급 계측기 메타** 지점별 공개: 준공일, 수심, 구조물 높이, WGS-84 좌표, 센서 목록.
  - 상세 차트에 **1일전/7일전/30일전 토글**, 다운로드는 **접근코드 발급(gated)** — 연구 수탁자 자세.
  - **CCTV/실시간 영상**(이어도 옥상·북쪽 등) — 4개 국내 사례 중 유일한 시각적 상황인지 기능.
  - 정직한 운영 고지: 망 교체로 이어도/가거초 실시간 데이터 일시 중단 안내(복구 예정 표기).

## 1-B. NOAA (기준 표준, 가장 깊게 확인)

### NOAA NDBC (National Data Buoy Center) — ndbc.noaa.gov ★★
- **URL:** https://www.ndbc.noaa.gov, 지점예: `/station_page.php?station=41001`, 이력 `/station_history.php?station=41001`, 용어집 `/faq/measdes.shtml`, QC `/faq/qc.shtml`, 원시피드 `/data/realtime2/41001.txt`
- **주목할 점(부이 모니터링의 사실상 표준):**
  - **지도 = 다이아몬드 마커, 색 = 데이터 신선도 상태**: 노랑=최근 데이터 있음 / 주황=과거 데이터만 / 빨강=최근 8시간 무데이터(쓰나미 지점 24h) / **깜빡이는 노랑=쓰나미 이벤트 모드**. → 우리 정상/지연/미수신에 **직접 대응**하는 표준 인코딩.
  - **위협 + 상태를 한 지도에**: 태풍/열대저기압 심볼을 같은 지도에 겹치고 "불확실성 원뿔은 경로만 표시하며 폭풍 크기는 아님"이라는 명시 고지.
  - 필터: **Program·Owner 드롭다운 + 지역 선택**, 지도에서 **KML 내보내기**.
  - **실시간 관측표 + 롤링 24시간 표**. 파라미터·단위: WDIR(풍향 true°+16방위 라벨), WSPD/GST(풍속/돌풍), WSPD10M/20M(고도 환산), WVHT(유의파고), DPD(최대파주기), APD(평균파주기), MWD(평균파향), PRES(기압)+**PTDY(3시간 기압경향)**, ATMP/WTMP/DEWP, VIS, TIDE, 파생 HEAT/CHILL/ICE.
  - **스웰/풍파 분리**(SwH/SwP/SwD, WWH/WWP/WWD)와 정성 **"Wave Steepness"(SWELL/AVERAGE/STEEP)** 분류.
  - **서브시간 극값**: "최근 1분 최저기압/최고풍속"을 각각 자체 타임스탬프와 함께 — 시간평균만이 아닌 순간극값 노출.
  - **단위 Imperial⇄Metric 토글 + 타임존 선택(15+)**, 기본 GMT/UTC. 파라미터마다 **작은 그래프 아이콘 → 5일 시계열** + 조합 패널(바람+기압).
  - **QC 철학 = 플래그가 아니라 제거(removal)**: 불량은 웹 게시 전 제거. 대신 45일 실시간 피드는 "gross error checking only"라고 **솔직히 캡션**, 아카이브(월/연)는 완전 QC. 결측 = 리터럴 **"MM"**.
  - **이력**: 1976~현재 **연도별 gzip 파일**(표준기상·연속바람·스펙트럼파랑밀도/방향·ADCP 해류·보조측정), **임계값 검색 도구**, 기후요약표. 커버리지 공백을 숨기지 않음.
  - **계측기 메타 완비**(지점 41001): 선체형식 "3-meter foam buoy with SCOOP payload", 수심 4,450 m, watch circle 4,651 yd, **센서 고도 정밀**(기온센서 3.7 m, 풍속계 4.1 m, 기압 2.7 m, 수온 -1.5 m), LLNR 번호, 소유/운영자 귀속(대학·타기관 소유 명시). **지점 사진(촬영 UTC 시각 + "주간 매시 촬영" 고지).**
  - **용어집 정의가 과학적**: WVHT = "20분 표본 중 상위 1/3 파고의 평균" — 마케팅 문구가 아닌 실제 해양학 정의.
  - 데이터 접근: 45일 텍스트, 연도별 아카이브, **NetCDF/THREDDS**, RSS. 표준 포맷(헤더 2행: 컬럼명 + 단위, 이후 고정폭) = 사실상 교환 표준.

### NOAA CO-OPS Tides & Currents — tidesandcurrents.noaa.gov
- **URL:** https://tidesandcurrents.noaa.gov, 지점 `/stationhome.html?id=8518750`, 수위 `/waterlevels.html?id=8518750`, 데이텀 `/datums.html?id=8518750`, API `api.tidesandcurrents.noaa.gov`
- **주목할 점:** (SPA라 지도 픽셀은 API/검색으로 보완)
  - 지도 레이어 필터 = **센서 유형별**("Water Levels Only / Met Only / Both / Currents") + 지역. 빈 조합엔 **"No station data found…" 빈 상태 메시지**.
  - **데이터 생애주기 노출**: Preliminary(잠정) vs **Verified(검증)**, 그리고 Hourly/Daily/Monthly Mean, High/Low, 예측(Prediction). → 관측·검증·예측을 **명시적 데이터 클래스**로 구분하는 핵심 패턴.
  - **API가 값마다 통계 노출**: `v`(값)·`s`(1초 표본의 **시그마/표준편차**)·`f`(4부 플래그 문자열: 3σ 초과 개수·flat·rate-of-change·max/min 초과)·`q`(p/v). → **불확실성(시그마) + 범주 플래그 + 잠정/검증 생애주기**의 기계판독 QC.
  - **데이텀/시기 버전관리**: MHHW·MHW·MSL·MLLW…, "Present(1983–2001) vs Superseded(1960–1978) 조석 epoch" 선택 — 방법론 변경을 추적·공개.
  - 지점 **설립일(예: 1920년 설립)** = 100년 기록의 신뢰 신호, 센서 인벤토리 공개, 예보 nowcast+48~72h(Coastal Condition Forecasts), 조위예측에 **"Official"** 명시. 하위기관 계보(CO-OPS under National Ocean Service) 푸터 공개.

## 1-C. 유럽

### Copernicus Marine Service (CMEMS) — marine.copernicus.eu
- **주목할 점:**
  - **테마 가능 중립 베이스맵**(다크/라이트/수심/무배경) + 3투영(적도·남/북극) + **색맹 모드** — 1급 토글. "국경 표현 민감성 회피"를 명시적으로 설계.
  - **레이어 스택 방식**: 격자장(색맵·min/max 조절) + in-situ 점/선/면을 위에. 하단 **시간 슬라이더** + 우하단 **수심 슬라이더**(4D 항해).
  - 클릭 시 자동 플롯(시계열·수직프로파일·시간-수심 Hovmöller), **핀을 다른 핀 위로 드래그해 겹쳐 비교**.
  - 설정에 **"불량 QC 플래그 in-situ 지점 표시/숨김"** 토글.
  - **표준 QC 플래그 0–9**(In Situ TAC/NetCDF): 0 미검사, **1 good, 2 probably good, 3 bad-보정가능, 4 bad**, 5 변경, 8 보간, 9 결측 — 플래그 0은 배포 안 함.
  - 제품마다 **DOI + Product ID + Quality Information Document + 원 데이터센터 + 갱신주기**. NetCDF 정본, 그래프 창에서 CSV/SVG, 대용량은 CLI/Python 생성 "Automate" 버튼.

### EMODnet Physics — emodnet.ec.europa.eu/en/physics
- **주목할 점:**
  - **플랫폼 유형별 색 구분**(추정): 고정=빨강, 표류부이=보라, 글라이더=노랑, 프로파일러=파랑, ARGO=초록, 페리박스=검정 + HF레이더·조위계 별도. **4,400+ 플랫폼**.
  - **2축 필터: 플랫폼 유형 × 파라미터**(예: "파고 재는 계류부이"만 격리) — 가장 깔끔한 멘탈모델.
  - **SeaDataNet L20 플래그 0–9** + 일부 **IOOS QARTOD**(GOOD/UNKNOWN/SUSPECT/FAIL/MISSING) + **처리모드 플래그**(`_DM`: real-time/provisional/delayed/mixed).
  - **모든 데이터셋 메타에 데이터 원제공자 이름 필수**(이용약관). 뒤에 **ERDDAP**(griddap/tabledap/Make-A-Graph/WMS/구독알림). EC·DG MARE 브랜딩, ISO 19115 메타.

### Cefas WaveNet (UK) — wavenet.cefas.co.uk
- **주목할 점:**
  - 지점 상세에 **정확한 위경도·수심·부이 모델**을 산문으로: 예 "Dowsing … 22 m 수심 … Directional Waverider MkIII". 파라미터: Hs, 수온, Tp(peak), **Tz(zero-crossing period)**, 우세파향, **파향 확산(spread)**. **30분마다 방향 스펙트럼** 생성.

### Marine Institute Ireland (데이터 부이망) — marine.ie / erddap.marine.ie

# 2. 횡단 관찰 — 실제 운영 플랫폼이 "신뢰"를 만드는 반복 패턴

조사한 15개 안팎의 플랫폼에서 **반복적으로** 나타난, "목업"과 "운영도구"를 가르는 신호들:

1. **상태 = 데이터 신선도로 색 인코딩** (NDBC 노랑/주황/빨강 다이아). 부이가 "살아있는가"를 지점 열기 전에 즉시 전달. 가장 재사용성 높고 값싼 신뢰/사용성 패턴.
2. **단위 + UTC 타임스탬프 + 로컬 타임존 토글을 어디에나** (NDBC·CO-OPS·Marine Institute·Puertos·WA 전부 비타협). 단위 없거나 모호한 로컬시각은 즉시 "아마추어"로 읽힘.
3. **QC 상태를 값 자체에 부착**(각주 아님). NDBC "gross error checking only" 캡션, CO-OPS **preliminary/verified + 시그마 + 플래그**, Cefas 공개 임계값. 표준 플래그 스킴(SeaDataNet/Copernicus **0–9**, IMOS/ARGO, Marine Institute 최소형 **0/1/9**).
4. **실시간(비QC) vs 검증(QC) 자료의 명시적 2계층** (CO-OPS·IMOS·WA·KHOA). 모든 숫자를 동등하게 권위 있는 척하지 않는 정직함.
5. **지점별 계측기 메타 공개**(NDBC 선체형식·수심·센서고·watch circle, CO-OPS 센서 인벤토리+설립일, Cefas "Waverider MkIII in 22 m", KIOST 준공일·수심·높이). **싸게 만들 수 있으면서 "진짜처럼 보이는" 최대의 신호.**
6. **결측 규약을 명시·시각 구분**(NDBC "MM") — 빈칸/0으로 거짓 정밀 암시 금지.
7. **정보 깊이의 계층 진행**: 실시간 표 → 시계열 플롯 → 이력/일괄 다운로드 → 용어집/정의. + **시각 SPA와 데이터포털/API를 분리**(국내외 공통).
8. **명명된 데이터 출처/원제공자**(EMODnet 의무화, NDBC 소유자 귀속, KIOST 출처 사슬) + 기관/프로그램 브랜딩.
9. **관측 vs 예보 명시 구분과 겹쳐보기**(Puertos SIMAR 검증, CO-OPS 예측/실측/검증 클래스, JMA "모델이 공식예보와 다를 수 있음"). — 신뢰성의 최상급 차별화.
10. **정량 임계·정의를 대중에게 공개**(KMA 특보 14 m/s·3 m, Cefas QC 임계, NDBC WVHT 정의, QLD Hsig 정의). 지표를 "가르치는" 투명성.
11. **가동률/완결성 시각화**(JAMSTEC Availability Plot, NDBC 커버리지 공백 노출)를 신뢰 신호로.
12. **공식 인증/배지·색표준**(NIFS UNESCO·ISO 9001, CMEMS DOI+QID, Marine Institute CC BY 4.0, JMA 배색 지침).

# 4. 즉시 실행 체크리스트 (우선순위 상위 10 — "목업 → 운영도구")

가장 적은 노력으로 "신뢰도" 인상을 가장 크게 바꾸는 순서(전부 **보유 데이터로 실현 가능**):

1. **[D1] 지점 제원 블록** — 부이형식·센서고·수심·관측개시일·정밀좌표·기관을 상세 헤더에. (가장 큰 지렛대, NDBC/CO-OPS/Cefas 공통 신뢰 신호)
2. **[C2/C4] 시각·주기 정직 표기** — 모든 값에 "관측 HH:MM(KST) · 주기 ~N분 · 경과 X분". 화면 갱신시각 별도.
3. **[Q1/Q2] QC를 값에 부착 + 표준 0–9 플래그 범례** — 기관QC(AQC/MQC)+알고리즘QC를 시계열에 마커/음영, 범례로 의미 명시.
4. **[D2/D3] 단위 병기·유효숫자 일관 + 24h 통계(평균/최대/최소/σ)와 극값 타임스탬프** — 연구 그레이드 인상.
5. **[M1] 상태 색 규약 명문화** — 정상/지연/미수신을 신선도 임계와 함께 범례에 수치로. (NDBC 노랑/주황/빨강 대응)
6. **[Q5] 정상범위 밴드 + 특보 임계선(파고 3 m 등)** — 차트에 ReferenceArea/Line.
7. **[Q4] 결측 명시(—)·차트 갭 처리** — `-99`를 0/빈칸으로 두지 않기.
