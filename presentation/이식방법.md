# 발표 대시보드 이식 명세서

> 이 문서는 **서버의 Claude(또는 담당자)에게 이식 작업을 요청하는 명세서**입니다.
> 아래 절차대로 진행하고, 마지막 "검증 체크리스트"까지 완료한 뒤 결과를 보고해 주세요.

## 1. 목적

국토지리정보원 발표용 HTML 슬라이드 대시보드(총 17페이지)를 이 서버에서 정적 웹으로 서비스한다.
원래 발표자 PC(Windows)에서 `python -m http.server 8787`로 로컬 서빙하던 것을 서버로 옮기는 작업이다.

## 2. 패키지 구성

```text
이식페키지/
  web/
    index.html          # 슬라이드 본체 (CSS/JS 인라인, 단일 파일)
    assets/             # 이미지·폰트·영상 57개, 약 150 MB
  scripts/
    start_server.sh     # Linux 실행 스크립트 (python3 http.server, nohup)
    stop_server.sh      # Linux 중지 스크립트
    start_server.ps1    # Windows 실행 스크립트
  이식방법.md            # 본 문서
```

- 모든 리소스는 **상대경로**로 참조하므로 폴더째 옮기면 어느 경로/포트에서도 동작한다.
- DB, 백엔드, 빌드 과정 없음. 순수 정적 파일이다.

## 3. 요구사항

| 항목 | 내용 |
|---|---|
| 런타임 | python3 (http.server 모듈만 사용) — 또는 nginx 등 아무 정적 웹서버 |
| 포트 | 기본 **8787** (사용 중이면 다른 포트로 변경 가능, 변경 시 인자만 다르게) |
| 디스크 | 약 160 MB |
| 방화벽 | 접속할 클라이언트 대역에서 해당 포트 인바운드 허용 |

## 4. 이식 절차

1. `이식페키지/` 폴더 전체를 서버의 원하는 위치로 복사한다. 예: `/opt/ngii_dashboard/`
2. 실행 권한 부여 후 시작:

```bash
cd /opt/ngii_dashboard/scripts
chmod +x start_server.sh stop_server.sh
./start_server.sh 8787
```

3. (선택) 부팅 시 자동 시작이 필요하면 systemd 유닛을 등록한다:

```ini
# /etc/systemd/system/ngii-dashboard.service
[Unit]
Description=NGII Presentation Dashboard (static)
After=network.target

[Service]
WorkingDirectory=/opt/ngii_dashboard/web
ExecStart=/usr/bin/python3 -m http.server 8787 --bind 0.0.0.0
Restart=on-failure

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload && sudo systemctl enable --now ngii-dashboard
```

- systemd를 쓰는 경우 `start_server.sh`는 사용하지 않는다 (이중 실행 금지).
- nginx로 서비스할 경우 `root`를 `web/` 폴더로 지정하면 끝. 영상 탐색(seek)이 필요하면 python http.server보다 nginx가 낫다(Range 요청 지원).

## 5. 대시보드 구조 참고 (수정·검증 시 필요한 지식)

- **단일 index.html** 안에 17개 `<section class="slide">`가 있고, JS가 방향키/버튼으로 한 장씩 표시한다.
- **8페이지, 12페이지는 라이브 iframe 데모**다:
  - 8페이지: `http://192.168.2.78:8020/` (QC 시계열 브라우저, **내부망 전용**)
  - 12페이지: `http://112.121.26.163:8010/login` (취수구 해수온도 예측 시스템, 공인 IP)
  - 슬라이드 진입 시마다 iframe이 `?_ts=타임스탬프`를 붙여 자동 리로드된다 (index.html의 `reloadDemos()`).
  - 이 두 URL은 **이 서버가 아니라 클라이언트(발표 PC) 브라우저가 접속**한다. 즉 발표 PC가 해당 네트워크에 닿아야 하며, 서버 쪽 설정과는 무관하다.
- 표지 슬라이드는 mp4 배경 영상(최대 101 MB)을 로드한다. 첫 로딩이 느리면 정상이다.
- 폰트(Pretendard woff2)는 assets에 포함되어 있어 외부 인터넷 불필요.

## 6. 검증 체크리스트 (완료 후 결과 보고)

아래를 실제로 실행/확인하고 결과를 보고할 것:

1. `curl -s -o /dev/null -w "%{http_code}" http://localhost:8787/` → **200**
2. `curl -s -o /dev/null -w "%{http_code}" http://localhost:8787/assets/cover.mp4` → **200**
3. 브라우저(또는 headless)에서 `http://<서버IP>:8787/` 접속:
   - 표지(1페이지)가 뜨고 우하단 페이지 카운터가 **1 / 17**인지
   - 방향키(→)로 끝까지 넘어가는지
   - 3페이지 조직도에 파란 강조 박스, 5페이지 매출 차트 리빌 애니메이션 동작 여부
   - 8·12페이지 iframe: 접속 가능한 네트워크라면 대시보드/로그인 화면 표시, 불가하면 빈 화면(정상 — 위 5절 참고)
4. 다른 PC에서 `http://<서버IP>:8787/` 접속 확인 (방화벽 검증)

## 7. 주의사항

- `web/` 내용물은 **완성된 발표자료**다. 임의로 수정하지 말 것 (특히 index.html의 iframe URL, QR 이미지).
- 이 패키지는 원본(`D:\97_support\2026.07.20 국토지리정보원 발표\web`)의 **복사본**이다. 발표자 PC에서 내용이 갱신되면 패키지를 다시 받아 덮어써야 한다.
- 8페이지 데모(192.168.2.78:8020)는 발표 장소가 내부망일 때만 동작한다. 외부 발표라면 이 페이지는 시연 없이 넘어가거나 사전 스크린샷으로 대체할 것.
- 12페이지 로그인 계정은 화면에 표기된 대로 **(비보안 임시계정) ID: test / PW: test** — 발표 후 서비스 담당자에게 계정 정리를 요청할 것.
